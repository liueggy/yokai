# 阅读等待感优化

2026-10-22，本地实现与实机样本。

- 使用原选定模型，首个分块完成后提前显示；未处理区域使用原图2x铺底，不能当作AI增强区域。
- 可见源区域以归一化坐标排序，优先处理相交分块，完整输出及缓存仍包含整页真实推理。
- 首块后按8块且至少1秒限频发布快照，StateFlow只保留最新快照，结束清空；不写入半成品缓存。
- 保留缩放与中心，渐进替换不重新触发横页自动定位；实际滚动防抖，布局变化不反复取消推理。
- 分页阅读当前页完成后停留1.5秒，仅对已加载下一页预增强；当前页先于预取，预取成功缓存，后续进入页面可复用。
- 条漫只处理可见页，下一页离屏预增强尚未启用。预取开始后变为当前页能继续完成，但这条接续路径暂不输出中间帧。
